# Izcal OS integration: independent fact-check (phase 8)

*Checked: `reports/Izcal OS integration.md`, draft 0.1, dated 24 October 2026 (794 lines, untracked in the `spec-os-integration` worktree at 3b183d1). Checked on 24 October 2026 by a fact-checker who did not write the spec or its notes. The spec was not edited.*

*Method.* Read the method (`.claude/skills/first-principles-spec/SKILL.md`, phase 8, the note format and M-1 part 3), the spec in full and the four research notes in full. Fetched every external link in the spec (56) with a plain HTTP client and checked each relative link (8) on disk. For the load-bearing claims, the primary page was fetched and the claim found in its text: Microsoft Learn and Windows blog pages, Apple documentation through its published JSON alternates (text plus availability metadata), the Apple Platform Deployment guide, freedesktop.org and D-Bus specifications, the xdg-desktop-portal documentation, the systemd `logind.conf` man page, wayland.app protocol pages (protocol definitions and support tables), Bugzilla bug prose, the Fingerprint, Electron, Chrome, W3C and Mozilla pages, and the GNOME 50 and KDE Plasma 6.8 release announcements. Eight web searches went to the items with no known primary URL (GNOME 50 X11 removal, macOS 26.4 release notes, Firefox 81 media controls, xdg-desktop-portal 1.20.0 and 1.21.0 changelogs, Follina dates, "Over the Edge 2.0"). Corpus IDs were checked by grep in `reports/`, the ledger and `crates/`, and the code references with `ast-grep`. Counts, ID sets and arithmetic were re-derived.

*M-1 part 3.* No third-party project's source code, header, commit, diff or code review was opened. Search results that offered a Chromium source file (on gitlab.collabora.com) and a third-party commit page were not opened. Bugzilla bug pages were read for comment prose only; their patch, diff and review links were not followed. The SSIP link's redirect target (an HTML-preview proxy of a GitHub blob) was fetched only to see where the link lands; it renders nothing without JavaScript, and nothing was read from it.

*Not checked.* Security advisories other than MFSA 2007-23 and Electron (CVE-2021-43905, CVE-2024-38112 and `search-ms:` were left at the notes' Medium grade); the press-only rows (Windows 11 per-type defaults in 2021, `microsoft-edge:` blocking, Startup Boost, Outlook links); SMTC key routing, `Shell_NotifyIcon`, the Run key and the classic COM toast activator (WP rows already graded Medium); SSIP protocol details; the Gentoo portal-backend table; the Firefox SUMO page (it serves a JavaScript challenge); Chrome 77's external-protocol checkbox; the exact desktop Web Share support per browser and OS. No design judgement is made here; that is the critic's job.

## Summary

- **Claims checked: 92.** **67 correct**, **16 partly correct**, **3 wrong**, **6 unverifiable** in this pass.
- **Links checked: 64.** 56 external links: **56 resolve** (HTTP 200), **0 dead**. 8 relative links (the four notes, the audit, Stage 1, shell and security scope): **all 8 exist**. **Source-code links: 0 direct.** One judgement call: `[SSIP]` (`freebsoft.org/doc/speechd/ssip.html`) redirects to `htmlpreview.github.io/?https://github.com/brailcom/speechd/blob/master/doc/ssip.html`, a GitHub *blob* view of a file in the speech-dispatcher repository. The file is an HTML manual (prose), but the URL is a repository blob path, and it renders nothing without JavaScript. Two Bugzilla bug pages are prose, with patch links that were not followed (acceptable). One link definition, `[SEC]`, is never used.
- **Evidence trail (the notes, not the spec's links):** `windows_platform.md` row 4.5 cites a GitHub **pull request** (CommunityToolkit/Maui #3276). A pull request is a code review, so the citation breaks M-1 part 3, and the spec pulls that row in through Q-OI-8 ("[WP 4.3–4.5]"). The history and Windows notes also disagree on whether Mozilla's `firefox-source-docs` set-default page meets OD-7.
- **The decision-carrying Windows and Linux facts all hold.** Microsoft Learn's default-apps text, UCPD.sys, the `ms-settings:defaultapps?registeredAppUser=` deep link and its OS floor, the EEA 2025 type list and taskbar pin, the share-interop conflict, the URI argument-injection warning, the foreground rules, the 5-minute Modern Standby rule and KB5074105 all match their primary pages word for word. So do the Desktop Entry, MIME-apps, D-Bus, Notifications, MPRIS and portal versions, the Wayland support tables, the logind 5 s default, GNOME 50's date and Plasma 6.8's date. The three wrong items are an internal contradiction between two targets, a misattributed macOS 26 prompt, and the code-review citation in the evidence trail.
