# Izcal DOM, bindings and event loop: independent design critique (phase 8)

Written 19 October 2026 by a reviewer who did not write the spec. Subject: `reports/Izcal DOM, bindings and event loop.md`, draft 0.1. Line numbers refer to the 930-line version of that draft as it stood when this critique was written (the author added the "Every ISA from the start" and "Interventions from content blocking" paragraphs during the review; both are taken into account). Method: `.claude/skills/first-principles-spec/SKILL.md`, phase 8, with `references/spec-template.md`.

**Scope.** The spec was read against: HGBA-2 2.3.2 (M-1, P1–P6, I-1 with its 2.1.2 extensions, BF-1); HGBA-3 (B1, B3, B4, B8, B9, B10); Stage 1 design (1, 2.1, 2.2 G1–G9, 3.3, 3.4, 4.1, 4.3, 5.1–5.4, 8.3); JavaScript engine spec 0.3.1 (JS-D4, JS-D13, JS-D15, JS-D17, JS-D18, JS-D20, 6.2, 6.5, 6.11, 6.12, 6.14, G6, G13–G18); resource footprint 0.3.1 (FP-D3, FP-D4, FP-D8, FP-4, FP-11, FP-32, FP-34, 6.3, 6.8, 6.9, 6.10); HTML and CSS parsing and style 0.3.3 (6.2–6.4, 6.6a, 6.10, 6.11, G19–G24); layout 0.3 (6.1, 6.9, 6.14, LY-D10, LY-D15); graphics and rendering 0.3 (GR-D15, 6.8, 6.9, 6.28, Q-GR-20); networking 0.3.3 (NW-D3, NW-D10, 6.1, 6.8); images and media (MD-D13, 6.6, 6.12, G56, MD-31); fonts and text (6.8, font installs); content blocking 0.2 (CB-D2, CB-D10, CB-27, I5, I11, `$popup`); DevTools 0.3 (recorded unit, execution points, 9.2); accessibility 0.2 (AX-D3, 6.3, 6.9, G100–G109, its 9.5 row for this spec); Phase 2 reconciliations and licence audit; Phase 3 ledger (G-4, G-11, G-13, G-16, G-18, G-19, C-6). The owner direction in the phase 2c brief was applied as binding.

**Phase artifacts.** Phases 1–7 are present (`frame.md`, seven strand notes, Sections 1–11). The template's sections are all there. Phase 8 had not run; this is half of it.

**Overall.** The spec's two central ideas are right and well argued: script points as types (DM-D5) and one stated, replayable task-selection policy (DM-D1). Most problems are at the edges where this spec meets something it does not own or that runs on another thread: what the mutation log must carry for its other consumers, which enqueue events are timing-dependent, what changes when each agent cluster gets its own thread, the in-process cross-origin cases that the "remote stub" argument does not cover, and the lifetime of security proofs and message-origin bindings.

**Counts: 35 findings: 9 High, 17 Medium, 9 Low**, plus 4 engine-source and licence items (E1–E4).

## What the spec gets right (keep in revisions)

- **Script points as types** (DM-D5): `&mut ScriptToken` on every call that can run script, script-free cores for the steps DOM marks atomic, IDs across call-outs, and two-phase bindings that make Web IDL's "convert, then act" order a type. This answers the record in [SR 3][SR] directly.
- **One stated, replayable task-selection policy** (DM-D1) with input first, starvation bounds, and DevTools showing the runnable set and the rule that chose.
- **No nested event loops**: dialogs and sync XHR as explicit scheduler states.
- **The broker decides** history, sandbox flags, activation of record and worker lifetime from facts it observed (G94, DM-D20).
- **Cross-site windows as remote stubs** with the 13 + 2 operations generated from HTML's tables, and a proof type for same-origin access (to be tightened per C4 and C5).
- **Effect facts trusted only when the auditor checks them** (DM-D4), and the IDL compiler's model reused for the fuzzer.
- **`unload` exactly as HTML's salvageability model says** (DM-D9), and `no-store` pages cached with eviction rules (DM-D14).
- **One structured-clone wire format with one decoder**, Kani harnesses and no author code in deserialization (DM-D12, G95).
- **`localStorage` without synchronous IPC**, following NW-D10's pattern (DM-D11, once C17 is fixed).
- **Ownership tables** with the editing, storage, SVG and animation specs that do not yet exist, and a clear M-1 section.
- **Falsifiable targets** with thresholds and failure actions for nearly every claim, including planted-bug suites with mutation-generated variants (DM-10, DM-11).
