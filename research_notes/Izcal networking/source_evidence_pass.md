# Izcal networking: source-evidence pass (M-1 2.3.1)

Date: 19 October 2026. Applies HGBA-2 2.3.1 M-1 part 3: another engine's source code (code files, headers, build manifests, commits, diffs, code reviews) is never evidence. Allowed: published prose (papers, documentation and prose design documents even if hosted in a repository, talks, blog posts, newsletters, release notes, bug-tracker discussion text, standards threads) and black-box observation. Scope: `reports/Izcal networking.md` (revision 0.3.1) and every file in this folder.

Forbidden sources are named below in plain text, never as links.

**Counts.** 26 engine-source links: **15 replaced** by published prose, **9 turned into black-box measurements**, **2 removed**. 15 unlinked claims read from engine source (U11 has three parts): 2 replaced, 4 turned into measurements, 11 removed. Prose documents hosted in repositories, and sources outside the rule (not another engine's source), are kept and listed at the end. No decision's recommendation changed. No target threshold changed. One open question was added (Q-NW-12, the black-box observation plan), and Q-NW-2 lost its outside context.
