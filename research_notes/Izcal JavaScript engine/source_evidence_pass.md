# Izcal JavaScript engine: source-evidence pass (M-1 2.3.1)

Done 19 October 2026 for spec revision 0.3.1. HGBA-2 2.3.1 adds M-1 part 3: another engine's source code (code files, headers, commits, diffs, code reviews) is never evidence. No spec or research note links to it or takes a constant, data layout or algorithm from it. Evidence is published prose (papers, documentation and prose design documents, even when hosted in a repository, talks, blog posts, release notes, bug-tracker and standards discussions) and black-box observation.

**Method.** Every link in `reports/Izcal JavaScript engine.md` and in this folder was matched against engine source hosts and paths (`chromium.googlesource.com`, `source.chromium.org`, `searchfox.org`, `hg.mozilla.org`, `github.com/<engine>/…/blob|tree|commit`, Gerrit, Phabricator, `codereview`, and `*.cc`, `*.h`, `*.cpp`, `*.rs`, `*.java`, `*.yaml` files in engine repositories). The text was also read for claims without links, such as "V8's source sets X". For each item:

1. **Prose**: the item was replaced with a published prose source that states the same fact, and that source was read to confirm it.
2. **Measurement**: a value or behaviour with no prose source became a black-box observation, naming where it is or will be measured.
3. **Removed**: the claim was dropped, and any argument that relied on it was checked to stand from first principles.

**Totals.** 18 links: 14 replaced with prose, 3 turned into black-box measurements, 1 removed. Of these, 5 are in the spec (3 prose, 1 measurement, 1 removed) and 13 are in the notes (11 prose, 2 measurement). Six unlinked claims taken from engine source were also removed or restated. No decision (JS-D1 to JS-D21), target or threshold changed, and no decision lost its support.

## Decisions and thresholds

- **No decision's support weakened.** JS-D1's address-width argument now has a direct primary source (the Linux kernel's 5-level paging documentation). JS-D16 keeps its precedent through the V8 sandbox README, which is prose. JS-D15 and the determinism rule rest on M0's own black-box result. The typed code-table item (JS-D16, JS-D19) never depended on the removed V8 header.
- **No target threshold changed.**
- One new fact for the owner's information: CDP's documentation now says V8's live edit (`Debugger.setScriptSource`) is no longer supported (N5). Nothing in the spec or in DevTools spec 0.3's use of this note depends on it, but it strengthens the note's point that live edit is a weak precedent.
