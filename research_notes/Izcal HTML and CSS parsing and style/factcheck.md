# Izcal HTML and CSS parsing and style: fact-check (phase 8)

Checked 19 October 2026 against `reports/Izcal HTML and CSS parsing and style.md` (draft 0.1) by a checker who did not write the spec or its notes. Primary sources were re-read directly: Mozilla Bugzilla and WebKit Bugzilla through their REST APIs (bugs 1385982, 1431285, 1331578, 1397380, 1404633; WebKit 297655, 301090); Chromium commits through Gitiles JSON and the GitHub mirror; whatwg/html commits and issues through the GitHub API; the HTML Standard's multipage `parsing.html`, `dynamic-markup-insertion.html` and `xhtml.html` as served today; the CSSWG editor's drafts of Values 4 and 5, Cascade 5 and 6, Selectors 4 and Syntax 3; `@webref/css` 8.7.7 from the npm registry; a clone of html5lib-tests at `c777c40`; a sparse checkout of WPT at `4ad507b`; the wpt.fyi stable-run summary files (Chrome 155.0.8059.84, Firefox 158.0, Safari 27.0, 18–19 October 2026); vendor blog posts as fetched pages. Cloudflare blocked Mozilla Hacks, so its Wayback copy was read. For the parser depth caps, engine sources were read for the constant only (a black-box fact, M-1 part 4). No personal data was sent in any request.

Verdicts: **Correct**; **Partly** (the substance holds but a number, scope, citation or wording is off); **Wrong**; **Unverifiable** (the cited source does not contain the claim, and no other source was found). "Must-fix" marks a finding that a decision (ST-D1 to ST-D19) or a target depends on, or a plain factual error. Every other fix is recommended. Rows marked "Not re-checked" were left to the notes' own grading because the search budget went to the claims that carry decisions.

### Must-fix list

1. **Blink background-parser deletion** (summary, 2.1, 4.4). The 2022 commit says the old parser was "no longer being used". "Less complicated" comes from the 2020 commit that introduced the foreground parser and states its author's expectation. Cite both, and in 4.4 cite HP 2.7–2.8.
2. **Stylo "≈1.3× at 6 threads"** (2.1, 2.2, 4.4, 5, 6.12, 9.5, 10). It comes from one MotionMark stress test bound by a malloc spinlock, which Mozilla could not reproduce. Firefox caps style threads at 6 because gains "level off". Restate it as that, not as Stylo's measured scaling.
3. **"Every mXSS and sanitizer bypass on record"** (summary, ST-D1, 4.4). The evidence is SR 2's 11 rows. The Chrome 146 bypasses that 4.4 cites were attribute-name and URL micro-grammar checks, not HTML-parser fast paths. Narrow the claim and re-cite.
4. **Nexus 7 "single-core phones"** (2.1, 4.4). The Nexus 7 is a quad-core tablet.
5. **Blink's property table: "~950 entries" → 835** (2.1, 9.3; HP 6.5).
6. **ST-3's Stage 1 floors are above every shipping engine** for `css-conditional` (97 against 96.4), `css-shadow` (95 against 92.3) and `css-variables` (90 against 87.9). Stage 2's "whichever is lower" rule then lowers them.
7. **6.4 cites ST-25 for the speculation subset and says "strict subset".** The target is ST-9, which requires ⊆.
8. **Risks: "the parser changed four times in 2026"**. It changed more than ten times.
9. **Summary: "4–6 years† to parity"** against 9.3's ST-M5 at 4.5–6 years.

Recommended (not blocking): add inline primary links for the claims that carry decisions (Section 0); "universal by March 2026", not December 2025; "+20 MB" (not +10 MB) of Stylo memory going from 1 to 3 threads, and +2.4 MB after the fix; attach WebKit's 0.7% to `transition: all`; "a hot path", not "the hot path", for fragment parsing in Speedometer 3; 594 elements (2024) and 613 rules (2022); "tokenizing is unlikely to be the bottleneck"; Values 4 `#calc-range` (§10.12); 168 computed-value texts; three hardening commits plus one change in the sanitizer commit; "Selectors 4 describes" partitioning; the Stylo OOM signature was not ranked "main"; WebKit's 2014 removal had no stated reason; B6 is not quoted verbatim; ST-8 (a) cites G22 for a rule G22 does not state; the 6.15 layer placement; move CVE-2026-2441's root cause and the depth caps out of 11.2's unverified lists; record webref's MIT package licence in Q-ST-1.
