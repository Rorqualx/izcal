# Izcal images and media: formats and codecs (specifications, conformance, usage, patents)

Compiled 19 October 2026. Primary sources were preferred (papers, specifications, maintainers' posts, release notes, issue trackers).
Confidence: **High** = primary source read and the claim checked in its text; **Medium** = primary abstract or snippet, or a vendor claim without data; **Low** = secondary source only.

**Method notes.**
- About 40 web searches and fetches were used. RFC texts (6386, 6716, 8251, 9639, 9649) and RFC Editor metadata were downloaded and read locally. Rows built from prior knowledge that were not re-fetched this session are graded **Medium** (well-known primary facts) or **Low**, and are listed in "Claims not verified".
- No source code of any codec library or browser was read (M-1). Two specifications are themselves defined by reference C code inside the RFC (VP8, Opus; rows 3.3, 4.1). That is a specification, not another engine, but it raises an M-1 question recorded in the open questions.
- Patent and royalty facts are what licensors publish. Their terms say the licence agreement is the only definitive statement. Nothing here is legal advice; it records facts for the legal review that Stage 1 design 13.2 already requires before M7.

## Open questions and black-box measurements needed

- **Q1 (M-1 ruling).** VP8 (RFC 6386) and Opus (RFC 6716) are normatively defined by reference C code inside the RFC, under the IETF's BSD licence. Is reading normative code in an RFC "a specification" (allowed) or "another engine's code" (forbidden)? The VP8 narrative alone is declared non-authoritative.
- **Q2.** Licence of the Argon AV1 streams, the AV1 conformance bitstreams, the VP9 and Opus test vectors, PngSuite, and JPEG XL 18181-3 codestreams, before they enter the test corpus.
- **Q3 (legal).** Does Via LA's AVC per-unit royalty apply to a browser distributed free (the page says "sold to end users")? Which entity counts units, and does Izcal exceed 100,000 units per year?
- **Q4 (legal).** Does Sisvel's AV1/VP9 pool claim royalties on free software decoders or only on "consumer products"? Has it asserted against any browser?
- **Q5.** AAC-LC and HE-AAC patent expiry by jurisdiction; whether the Via LA AAC pool covers a free browser.
- **Q6.** Current H.265 edition number and whether H.264.1/H.265.1 bitstreams are free.
- **Q7 (measurement).** Software AV1 decode speed of a Rust decoder with portable SIMD versus hand-written assembly on the rigs (`local`, `mini`, `rig253`), at 1080p and 4K, 8- and 10-bit, 1–8 threads; and energy versus hardware decode via `MediaCodec`.
- **Q8 (measurement).** Peak decode memory for AVIF and JPEG XL images at Baseline/Advanced limits (FP 6.5 asks for it).
- **Q9.** Which OS frameworks decode which formats on each Izcal OS (Media Foundation, VideoToolbox/AVFoundation, Android MediaCodec, Linux VA-API/V4L2), black-box probed, and how many fingerprinting bits the difference adds.
- **Q10.** AV1 Annex A exact text: profiles, level limits, and whether film-grain output is bit-exact for conformance (not re-read this session).
