# Izcal accessibility: specs_semantics

Compiled 19 October 2026. Primary sources were preferred: W3C and WHATWG specifications (editor's drafts and /TR versions, downloaded and read as text), the W3C ARIA Working Group's GitHub issue trackers, WPT results from the wpt.fyi API, the web-platform-tests interop repositories, the ARIA-AT app's public API, Open UI explainers, and one blink-dev intent thread.
Confidence: **High** = primary source read and the claim checked in its text; **Medium** = primary abstract or snippet, a summary of a long page, a vendor claim without data, or a well-known fact not re-checked this session; **Low** = secondary source only, or the researcher's recollection not checked against a source this session.

M-1 note: no engine source code was read for this note. No code files, headers, commits, diffs, code-review pages or source browsers of Blink, Gecko, WebKit, Servo, Ladybird or AccessKit were opened. WPT test files were not opened either: WPT numbers come from wpt.fyi's results API (file names and pass counts only). The webdriver PR #1960 discussion page mentions WebKit commits that list returned properties; those commits were not opened, and the property list from that page (row 9.6) is graded Medium. Browser support versions come from MDN browser-compat-data JSON (CC0 data, not code). Where this note says what an engine "does", it is black-box evidence (test results or a vendor's prose), not a shape to copy.

**Method notes**
- Web searches used by this strand: 4 (the session-wide search budget ran out at the fifth). Everything after that was fetched directly from known primary pages: w3c.github.io editor's drafts and www.w3.org/TR pages (downloaded with `curl`, converted with `pandoc`, and grepped or parsed locally), html.spec.whatwg.org multipage sections, drafts.csswg.org, the wpt.fyi `/api/runs` and `/api/search` endpoints, the GitHub REST API (repository metadata, licence files and issue lists sorted by comment count), the ARIA-AT GraphQL endpoint, and raw MDN browser-compat-data files.
- Role and property counts (rows 2.1–2.3) were computed by parsing the ReSpec HTML of WAI-ARIA 1.2 (Recommendation) and the 1.3 editor's draft; they are this researcher's counts, not counts stated by the specifications.
- WPT pass rates are a snapshot of the aligned stable runs of 19 October 2026: Chrome 155 (Linux), Firefox 158 (Linux), Safari 27 (macOS), Edge 155 (Windows).
- Could not obtain: Interop 2024's final "Accessibility" focus-area scores (the results-analysis CSV paths returned 404), the text of the HTML PR for `interestfor` (whatwg/html#11006), and the aria-actions proposal text (it is not in the ARIA 1.3 editor's draft). OS API documentation for text interfaces (row 5.12) was not re-read this session.
- Several /TR versions carry the date 12 October 2026 while their editor's drafts are older (for example AccName ED 29 May 2026). This is consistent with a same-day republication of the ARIA suite, but it was not confirmed.
