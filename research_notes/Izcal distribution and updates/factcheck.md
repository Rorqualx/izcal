# Izcal distribution and updates: fact-check (phase 8)

Date: 24 October 2026. Checker: independent fact-checker (did not write the spec or the notes).
Scope: `reports/Izcal distribution and updates.md` draft 0.1, against its four research notes, the primary sources it links, the CRA's Official Journal text, and the Izcal specs and code it cites.
Method: every linked URL fetched with `curl` (80 unique URLs) and the claim checked in the fetched text; Bugzilla checked through its REST API (bug metadata and comment 0 only); the CRA checked against the Official Journal XHTML of Regulation (EU) 2024/2847 from the Publications Office (Cellar, `publications.europa.eu/resource/celex/32024R2847`, OJ L series, generated 25 November 2024), because EUR-Lex returned a bot challenge (HTTP 202) to scripts; Implementing Regulation (EU) 2025/2392 read the same way. Internal IDs checked by reading the cited reports and `crates/hg-ipc-gen/idl/process.hgidl`. No web searches were used. No third-party source code was opened.

**Counts: 0 blockers, 2 majors, 36 minors.** Every CRA quote matches the Official Journal wording. Every dated claim the user asked about checks out except where a row below says otherwise.
