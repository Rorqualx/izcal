# Izcal DevTools spec: fact-check (phase 8)

Compiled 2026-10-18 by an independent fact-checker who did not write the spec. It covers `reports/Izcal DevTools spec.md` draft 0.1 (17 October 2026). Primary sources were preferred: specifications, maintainers' posts, release notes, issue trackers (Bugzilla REST, GitHub API), papers (read as full PDFs) and NVD. Every source below was fetched on 2026-10-18 unless marked otherwise.
Confidence: **High** = primary source read and the claim checked in its text; **Medium** = primary abstract or snippet, or a vendor claim without data; **Low** = secondary source only.

**Method.** I chose the claims that carry a decision, target or lesson, plus every "X failed or was removed because Y" in Sections 2 and 5. Each claim was checked against its primary source, and against the research note the spec cites for it. No file other than this one was changed.

**Verdict counts (60 claims):** Confirmed 49 · Corrected 8 · Misattributed 1 · Unverifiable 2. Several Confirmed rows still carry a citation or wording fix (claims 26, 32, 34); these are in Section 4.
