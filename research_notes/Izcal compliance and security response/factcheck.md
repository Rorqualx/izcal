# Izcal compliance and security response: fact-check

Compiled 24 October 2026, by an independent fact-checker (phase 8), against `reports/Izcal compliance and security response.md` draft 0.1 and its four research notes. The spec was not edited.
Confidence: **High** = primary source read and the claim checked in its text; **Medium** = primary snippet, or a vendor claim without data; **Low** = secondary source only.

**M-1 statement.** No third-party source code was opened. No code files, headers, commits, diffs, code reviews or repository data files were read. A search returned links into ETSI's `labs.etsi.org` repository for EN 304 617 (a commit and a raw `.md.backup`); they were not opened. Only the following were read: regulation and statute text (Official Journal, eCFR, California leginfo), standards prose (OASIS CSAF 2.0, RFC 9116, BSI TR-03183-2 PDF, CNA Rules 4.2.0 PDF), agency and vendor prose pages, and news coverage. The spec contains **no link to third-party source code** (its one `github` match is `docs.github.com` prose) and **no email address**. No value in the spec is derived from code: the spec's own flag on Chrome's severity guidelines (Section 7) is correct.

**What was reached.**
