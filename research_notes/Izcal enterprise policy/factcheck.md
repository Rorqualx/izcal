# Izcal enterprise policy: independent fact-check (phase 8)

Compiled 24 October 2026. The checker did not write the spec. Revision checked: *Izcal enterprise policy* draft 0.2, 858 lines, SHA-256 `e3016fd1698d7a461df0a3a3ccf079e5bc496fca32a6960cb197595bfd666254` (mtime 24 October 2026 23:35; Appendix A still reads "Filled in after phase 8").

**Method** (`.claude/skills/first-principles-spec/SKILL.md` phase 8). (1) Each claim that carries a decision or target was traced to the cited row of the three notes in this folder ([HP] `history_postmortems.md`, [OD] `os_delivery_formats.md`, [LG] `landscape_admin_gaps.md`). The priority claims were then re-read against the primary pages those notes cite, fetched on 24 October 2026 (Microsoft Learn, Apple developer documentation (JSON rendering), chromium.org and support.google.com prose pages, Mozilla's admin reference, SUMO and Hacks, the Flatpak docs, NVISO, Malwarebytes, and the BSI PDF V3.0). (2) Each citation was checked for strength against the note's confidence grade. (3) Every Izcal ID and section the spec cites was checked against `reports/` and the M1 code with grep and sed. (4) Links were checked. No third-party source code, commit, diff, code review or in-repository data file was opened. Where a page links only to a code repository (Mozilla's ContentAnalysis page), the link was not followed. The Chrome Blog (2014) and Chromium Blog (2015) bodies did not render (JavaScript), so only their dates were confirmed.

Verdicts: **Correct**; **Partly** (true but overstated, under-qualified, misattributed or mis-cited); **Wrong** (false as written, or contradicted by the source or the repo); **Unverifiable** (the primary text could not be read this session).
