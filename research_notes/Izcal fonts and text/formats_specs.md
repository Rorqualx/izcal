# Izcal fonts and text: formats and specifications

Compiled 19 October 2026. Primary sources were preferred (Microsoft Learn OpenType pages, W3C /TR documents, Unicode reports and data files, the WPT repository and wpt.fyi run summaries, chromestatus, standards-positions trackers). Where a number was computed by this researcher from a primary file, the method is stated and the date is the date of the file.
Confidence: **High** = primary source read and the claim checked in its text; **Medium** = primary abstract or snippet, or a vendor claim without data; **Low** = secondary source only.

M-1 reading used throughout: specifications, conformance suites and standards data (UCD, CLDR, emoji data) are oracles and generator inputs. Other projects' code (HarfBuzz, FreeType, Fontations, ICU, OTS, browsers) was not read. Fontations' `codegen_inputs` directory is named only as an existence fact (6.4); it is another project's artifact and is not an input under M-1.

Method notes:
- Word counts of spec pages were computed from the HTML with tags stripped (`len(text.split())`). They size the reading and anchoring effort; they are not normative sizes.
- Unicode test-file case counts are non-comment, non-blank lines of the 18.0.0 files downloaded on 19 October 2026. BidiTest.txt lines carry a bitset of paragraph levels, so its real case count is larger than its line count.
- WPT pass rates were computed from the wpt.fyi `summary_v2` files of the aligned stable runs of 18 October 2026 (WPT revision `23b0b89b1a`; Chrome 155.0.8059.84, Firefox 158.0, Safari 27.0). Per-file score = passing subtests / subtests, or 1/0 for a test without subtests (reftests); the directory score is the mean over the union of files. This is close to, but not identical to, the Interop scoring method.
- The web-search budget ran out after four searches. The remaining facts were checked by fetching primary URLs directly. Unchecked items are graded Medium or Low.

**Implications:** OpenType can be pinned by Microsoft page plus `ms.date`. The ISO 2026 edition is the only home of avar2, so the spec must name both sources and treat avar2 as an ISO anchor that Izcal cannot yet read verbatim (purchase or a public ISO copy needed). Every table parser will be written from prose, because no official machine-readable schema exists. A spec-derived description language (**FMT-DSL**) authored by Izcal from the prose, with an anchor on each field, is the natural first artifact. Shaping is anchored to the informative Microsoft script pages plus the UCD; where those are silent, the behaviour must be pinned by Izcal's own corpus, not by another engine's code.

The ~628k lines of Unicode test data are a cheap, exact oracle that must reach 100% at the pinned version. `hg-ucd` and `hg-intl` already pin a version for ECMA-402, so the text stack and Intl must share one pin.
