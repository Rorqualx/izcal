# Source-evidence pass (M-1, HGBA-2 2.3.1), Izcal fonts and text

19 October 2026. Applies HGBA-2 2.3.1's M-1 part 3: another engine's or engine library's source code (code files, headers, commits, diffs, code reviews, Gerrit or Phabricator changes, source-browser pages) is never evidence. Published prose (papers, documentation, prose design docs even when hosted in a repository, release notes, bug-tracker discussion, mailing lists, blog posts) and black-box observation are. Scope: `reports/Izcal fonts and text.md` (spec revision 0.3.1) and every file in this folder.

For each item: (1) replaced by a published prose source stating the same fact, checked by reading that page on 19 October 2026; else (2) for a value or behaviour, turned into a black-box measurement at a named milestone, with a first-principles † value where a number is needed now; else (3) removed, with the dependent argument re-checked. Forbidden sources are described below in words, never linked.

**Counts: 41 items: 17 replaced, 8 turned into measurements, 16 removed; 3 prose design docs kept.**

**Decisions whose support weakened:** TX-D16 (shaping cache): its "measured large win" rested on profile figures in a Ladybird commit message; it now rests on a qualitative published report (Ladybird newsletter, September 2025; Malkin and Daggett on www-style, 2012) plus first principles. The recommendation (a) is unchanged; Q-TX-14 (TX-M1) measures it. TX-D10's fuel placeholders lost their cross-check against HarfBuzz's current default (read from a header file); they are now argued from first principles in spec 6.3, values unchanged. **No target threshold changed.** Q-TX-14 adds a reconsideration trigger (cache saving under 10%† of shaping time).
